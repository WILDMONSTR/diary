API 인증 보안 점검

개발자 콘솔에 코드를 붙여넣을 필요 없이 버튼을 눌러 인증 거부 응답을 확인하는 임시 페이지입니다.

개인정보 및 데이터 보호 안내

이 페이지는 이메일, 비밀번호, Supabase 로그인 세션, localStorage의 내용을 읽지 않습니다. 실제 인증 토큰도 사용하지 않습니다. 세 번째 테스트는 테스트용 가짜 토큰 문자열만 전송합니다.

PUT 테스트는 인증 헤더 없이 빈 테스트 데이터를 보내지만, API는 데이터를 읽거나 쓰기 전에 인증을 검사하도록 구현되어 있습니다. 기대한 401이 아닌 다른 결과가 나오면 더 이상 테스트 버튼을 누르지 말고 결과를 확인하세요. 이 임시 페이지는 Production에 포함하지 않아야 합니다.

1. GET · 인증 헤더 없음
